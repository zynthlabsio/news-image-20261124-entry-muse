One 1024x1024 editorial poster summing up the world news of Tuesday
24 November 2026, built around the day's dominant story and designed to
read at a glance:

- **Lead:** Nvidia shares soar 31% as Jensen Huang is reinstated as CEO
  after pressure from President Trump — a surging green candlestick chart
  and a celebrating silhouette under the headline.
- **World Court:** the ICJ finds Myanmar guilty of genocide against the
  Rohingya — golden scales and a gavel.
- **Strait of Hormuz:** tankers hit mines and set ablaze in the strait,
  as Iran threatens to close it further.
- **Indonesia:** a factory fire in Banten kills 26, with dozens missing.
- **Ticker:** a car bomb injures 23 in Villavicencio, Colombia; Israel
  kills the Hamas internal security chief in Gaza; a Russian strike on
  Zaporizhzhia wounds 40; Ukraine sinks the Russian corvette Merkury off
  Libya; hundreds of bomb threats at German schools.

The artwork was generated for these stories and the headlines were set
over it in type, so every word on the poster is exactly the word meant.

## Run it

```sh
node main.ts
```

This writes `entry.png` (1024x1024, under 1 MiB) to the directory named
by `MAKEFUN_OUTPUT_DIR`, or to `/output` when that variable is unset.
Node 22 standard library only, no network: the program copies the
committed `entry.png`, so every run produces byte-identical output.
